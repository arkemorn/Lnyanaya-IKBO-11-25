# Эмулятор командной оболочки VFS

Учебный проект по конфигурационному управлению, вариант 18. Программа
предоставляет консольную оболочку с виртуальной файловой системой. Архив ZIP
читается в память; команды не извлекают файлы на диск и не изменяют архив.

## Требования

- Python 3.10 или новее.
- Дополнительные библиотеки не нужны.
- Сборка не требуется.

## Запуск

Интерактивный режим с пустой виртуальной файловой системой:

```sh
./run.sh
```

Запуск с ZIP-архивом и стартовым сценарием:

```sh
./run.sh --vfs path/to/files.zip --script scripts/demo.commands
```

В Windows используйте `run.bat`:

```bat
run.bat --vfs path\to\files.zip --script scripts\demo.commands
```

При старте программа печатает заданные пути в формате `ключ=значение`.
Приглашение содержит имя архива и текущий каталог, например
`user@files:~/docs$`.

## Параметры

- `--vfs` — путь к ZIP-архиву с файлами виртуальной системы. Если параметр
  пропущен, оболочка запускается с пустой VFS в памяти.
- `--script` — путь к стартовому сценарию. Непустые команды отображаются в
  консоли по мере выполнения; пустые строки и комментарии пропускаются.
  Ошибки выводятся, после чего сценарий продолжает работу до `exit` или конца
  файла.

Архив загружается без распаковки. Поддерживаются каталоги любой вложенности
и двоичные файлы. Команда `cp` меняет только дерево VFS в памяти.

## Команды

- `ls [путь]` — вывести содержимое каталога.
- `cd [путь]` — сменить текущий каталог; без аргумента перейти в корень.
- `head [-n число] файл` — вывести первые 10 строк или указанное число строк.
- `uniq файл` — убрать соседние одинаковые строки.
- `uname` — вывести имя операционной системы хоста.
- `cp источник назначение` — скопировать файл или каталог в VFS.
- `exit` — завершить эмулятор.

Парсер поддерживает аргументы в кавычках. Пути относятся к VFS, а не к
файловой системе компьютера.

## Пример работы

```text
user@files:~$ ls
notes.txt
user@files:~$ head -n 2 "notes with spaces.txt"
user@files:~$ uniq notes.txt
user@files:~$ exit
```

## Демонстрационные сценарии

Сценарии создают ZIP во временной папке, запускают эмулятор с обоими
параметрами и удаляют архив после завершения:

```sh
sh scripts/demo.sh
sh scripts/demo-nested.sh
sh scripts/demo-errors.sh
```

`demo-nested` использует каталоги глубиной не менее трёх уровней;
`demo-errors` показывает ошибки команд и обработку аргументов в кавычках.
В Windows доступны `scripts\demo.bat` и `scripts\demo-nested.bat`.

## Тесты

```sh
python3 -m unittest discover -s tests -v
```

## Структура проекта

- `src/cli.py` — параметры запуска, сценарии и интерактивный ввод.
- `src/shell.py` — команды и виртуальная файловая система.
- `tests/` — модульные тесты.
- `scripts/` — демонстрационные сценарии и создание временных ZIP-архивов.
- `run.sh`, `run.bat` — скрипты запуска.
