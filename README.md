# VFS Shell Emulator

Учебный проект: эмулятор командной оболочки с графическим окном.
Команды выполняются только над виртуальной файловой системой в памяти.

## Что нужно установить

- Python 3.10 или новее.
- Tkinter. На некоторых Linux его нужно установить отдельно
  (например, пакет `python3-tk`).

## Запуск

```sh
./run.sh
```

Запуск с CSV-файлом и сценарием команд:

```sh
./run.sh --vfs vfs/sample.csv --script scripts/demo.commands
```

Windows:

```bat
run.bat --vfs vfs/sample.csv --script scripts/demo.commands
```

## Команды

- `ls [путь]` — показать содержимое каталога.
- `cd [путь]` — перейти в каталог.
- `tail файл` — показать последние 10 строк файла.
- `uname` — показать имя эмулятора и имя компьютера.
- `du [путь]` — показать размер содержимого в байтах.
- `cp источник назначение` — скопировать файл или каталог.
- `mv источник назначение` — переместить или переименовать элемент.
- `conf-dump` — вывести параметры запуска в формате ключ=значение.
- `exit` — закрыть окно.

Пути относятся к виртуальной системе, а не к настоящему диску.

## CSV-формат VFS

CSV должен содержать три столбца:

- `path` — путь внутри виртуальной системы;
- `type` — `dir` для каталога или `file` для файла;
- `content_base64` — содержимое файла в Base64; для каталогов оставить пустым.

Вложенность задаётся путём, например `docs/week1/notes.txt`.
Данные CSV загружаются в оперативную память. Команды `cp` и `mv` не
перезаписывают CSV на диске.

## Стартовые сценарии

Файлы в `scripts/` демонстрируют обычную работу и остановку при ошибке.
Пустые строки и строки, начинающиеся с `#`, игнорируются.
Во время выполнения сценария отображаются команды и их ответы.
